# Intervene, Calibrate, Discover

Public presentation website for **Learning Causal Structure from Pixels**.

Project page: https://dzyy123.github.io/intervene-calibrate-discover/

This repository contains the website, English manuscript PDF, reported result tables
and demonstration media only. The research implementation, training datasets,
model weights and runnable source archives are not published here.

The private research repository and private website working repository retain
their own access restrictions. Public demonstrations and paper measurements
are distinguished on the website; this update adds a recorded demonstration
without changing the paper's benchmark tables.

The English paper is a non-anonymous preprint with the supplied seven authors and
five affiliations. Review line numbers and conference-review headers have been
removed. Website publication does not mean the paper has been submitted to arXiv.

The Chinese working manuscript is not part of the current public deployment.
The first featured film is the approximately 150-second, 1080p seven-node physical fork, retaining
all 20 rounds with Operate → Observe → Update stages and upright starts for
all 40 displayed trials. Green arrows match the simulator
reference; red arrows are incorrect current hypotheses. Withdrawn edges disappear.
The recorded run reaches the six-link reference graph in round 18 and retains it
through rounds 19–20. Reference coloring is display-only, never a learner input.

The fork is an exploratory extension, not a paper benchmark result. Its frozen
encoder and ACC are followed by revisable graph scoring. A failed F1 hold was
addressed by moving the grasp inward 5 mm, then rerunning all eight additional
rounds from round 12; learning rules and thresholds were unchanged. Accelerated
motion, the displayed-pair selection and the actuator correction are disclosed.

Rounds 5 and 7 now show existing upright pairs selected after the run for
presentation, with their corresponding endpoint images and readout captions.
All graph updates still use the original four-pair batches and graph history;
this is not a new upright-only learning experiment. The other 18 displayed
pairs are unchanged. New media use versioned URLs; earlier video URLs remain
available for compatibility with the previously released demo package.

The current edit is approximately 1.5× faster than the preceding 226.6-second
film, which remains available through the slower-version link. Physical scenes
were re-rendered at 2080×1170; the output is 1920×1080 with reduced compression
loss. All 40 model-input images and physical audits match the recorded trials.
No AI-generated image enhancement or new learning result is introduced.

The seven-node chain remains the second featured film. Balance is the third featured film
and also appears in the supplementary library; Pick-and-Place and the earlier four-domino
version remain in that library.

Balance now uses the approximately 89-second, 1080p task-state run with all 12 rounds.
Its repaired visual encoder and operated-value affine calibration are frozen during graph
acquisition. The closing withdrawal overlay fades out, leaving the four links actually
retained in the final selected graph. Colors indicate additions and withdrawals, not
reference correctness. This custom simulation demonstration is separate from paper
benchmark scores; the new code, weights, raw acquisitions and complete run records remain private.
All featured films have English in-video captions; the page interface supports
English and Chinese. Only the approved video, cover and sanitized chapter/scope
metadata are added here—not research scripts, raw acquisitions or checkpoints.
